# 🚀 Logicode Website

Official website for **Logicode - Coding Club, TKIET Warananagar**

## 📚 Description
The Logicode website will showcase our events, leaderboard, team members, and include a secure MCQ-based test platform.

## 🛠️ Tech Stack
- Frontend: React / HTML, CSS, JS
- Backend: Node.js + Express
- Database: MongoDB
- Deployment: Vercel / Render

## 🤝 How to Contribute
1. Fork this repo  
2. Clone your fork  
3. Create a new branch:  
   `git checkout -b feature-name`
4. Make your changes and commit:  
   `git commit -m "Added event page UI"`
5. Push to your branch:  
   `git push origin feature-name`
6. Open a Pull Request
